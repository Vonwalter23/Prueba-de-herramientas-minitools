# Prueba de herramientas PDF

Demo temporal y aislada para probar operaciones básicas con archivos PDF desde el navegador.

## Operaciones previstas
- Unir archivos PDF.
- Extraer páginas seleccionadas.
- Rotar páginas.
- Reordenar páginas.
- Eliminar páginas seleccionadas.

## Privacidad
El procesamiento está diseñado para ejecutarse localmente en el navegador. Los archivos seleccionados no se envían intencionalmente a un servidor.

## Estado
La demo aún no está publicada. GitHub Pages debe habilitarse y ejecutarse por separado después de cargar y verificar todos los archivos.
